# 학적 정보 보완 v0.2.4

사용자 제공 HS효성 화면의 항목을 기준으로 확장의 인식 범위를 확대한다. 실제 HTML은 아직 관찰하지 못했으므로 특정 사이트 선택자를 추정하지 않는다.

## 처리 흐름

1. 모아에서 학력 기록 하나를 가져온다.
2. 일반 입력·select는 기존 라벨과 title 및 가까운 짧은 학적 제목으로 연결한다.
3. 학위/입학/졸업 radio 그룹은 실제 표시 문구로 연결하며 신입학=입학, 편입학=편입, 졸업 예정=졸업예정만 동등하게 처리한다. 기존 선택·그룹 교체·애매한 중복은 건너뛴다.
4. 학교·전공은 사용자가 검색 시작을 누른 뒤 열린 dialog에 이름을 넣고 검색한다. 검색 시작·검색어 입력·결과 조회·결과 선택은 별도 동작이며 모두 같은 탭, 주소, 스캔 상태를 확인한다. 이전 스캔 결과로 입력할 수 없다.
5. 결과는 이름이 정확히 일치하는 선택 가능한 요소 한 개일 때만 표시한다. 자동 선택하지 않고 사용자가 선택을 누른다. 선택 결과의 서버 저장 여부는 추정하지 않는다.

## 한계와 제외

- 비표준 팝업·새 창·iframe·별도 행 선택 버튼 등은 실제 DOM 확인 전 지원하지 않는다.
- 기존 학교·전공을 바꾸는 별도 검색 실행은 사용자가 명시적으로 시작한다. 일반 빈칸 채우기에 검색 버튼 클릭을 섞지 않는다.
- 본교/분교, 주야간, 학과/전공계열은 저장 데이터가 없어 추정하지 않는다.
- 연월을 날짜로 바꾸며 1일·말일을 임의 생성하지 않는다.
- 자소서·연락처·비밀번호·동의·지원서 저장·제출은 처리하지 않는다.

## 검증

기존 전체 검사, 가상 DOM에서 학적 라벨/radio/검색 흐름/기존값/중복/상태변경 보호, 브라우저 가상 양식 학적 6개 및 학교 검색·선택 검증. 실제 HS효성 성공과 구별한다.
